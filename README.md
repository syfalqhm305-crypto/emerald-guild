# نقابة الزمرد — نسخة قاعدة بيانات حقيقية

هذه النسخة مبنية على الواجهات الموجودة في ملف Stitch، وتم توصيلها بـ Supabase (Auth + Postgres + RLS) بدون إزالة الهوية البصرية الداكنة/الزمردية.

## الملفات الأساسية
- `index.html` البوابة الرئيسية.
- `register.html` تسجيل عضو حقيقي.
- `bank.html` دخول البنك.
- `bank-dashboard.html` حساب العضو والرصيد والمعاملات.
- `store.html` المتجر العام وقراءة المنتجات من قاعدة البيانات وتسجيل الطلبات.
- `admin-login.html` دخول المسؤول.
- `leader.html` لوحة القيادة الرئيسية للمسؤول.
- `store-admin.html` إدارة المتجر وإضافة منتجات حقيقية.
- `supabase/schema.sql` مخطط قاعدة البيانات + RLS + Trigger.
- `js/config.js` مكان وضع رابط Supabase والمفتاح العام.

## التشغيل
1. أنشئ مشروعاً في Supabase.
2. افتح SQL Editor وشغّل كامل الملف `supabase/schema.sql`.
3. من Supabase → Project Settings → API انسخ Project URL والمفتاح العام (publishable/anon) إلى `js/config.js`.
4. أنشئ أول حساب من `register.html`.
5. في SQL Editor نفّذ السطر الموجود في نهاية `schema.sql` بعد استبدال البريد ببريد حسابك ليصبح `admin`.
6. ارفع المجلد كما هو إلى GitHub أو Vercel. لا تضع Service Role Key داخل الموقع؛ المتصفح يستخدم المفتاح العام فقط، بينما RLS تحمي البيانات.

## ملاحظات
- الرصيد EMD هنا رصيد داخلي للنقابة، وليس أموالاً حقيقية أو تكاملاً مع بنك/بوابة دفع.
- المتجر متاح للزوار، والطلبات تحفظ في جدول `orders` بحالة `pending`.
- صلاحيات المسؤول مبنية على دور `admin` داخل قاعدة البيانات، وليس على إخفاء الرابط فقط.
