# موقع نقابة الزمرد السيادية

## هيكل الملفات
```
index.html            الواجهة الرئيسية: نبذة + لوجو، دخول للبنك، تسجيل عضو، الإحصائيات،
                       تسجيل دخول المسؤول (أعلى الصفحة)، دخول للمتجر، القادة والنواب، تواصل واتساب
register.html          طلب انضمام وتوثيق عضو (يذهب لإدارة البنك للموافقة)
member-dashboard.html  لوحة العضو: اللقب، الأيدي، الرصيد، العمليات، الطلبات المعلقة، تحويل/إيداع/سحب
store.html             المتجر العام (بدون قيود أو تسجيل دخول) — طلب فوري + واتساب
bank-admin.html        لوحة تحكم مسؤول البنك: إضافة/تعديل/حذف الأعضاء، الرتبة، الرصيد،
                       الأيدي، الباسورد، اللقب + اعتماد الطلبات المالية وطلبات الانضمام
store-admin.html       لوحة تحكم مسؤول المتجر: إضافة سلع، قبول/رفض الطلبات الواردة
sovereign.html         لوحة القيادة العليا: تغيير أرقام واتساب المسؤولين، تغيير كلمات مرور
                       البنك/المتجر/نفسها، بيانات النقابة والشعار، نسبة العمولة، سجل الحركات

shared/
  tailwind-config.js   إعدادات التصميم (الألوان/الخطوط/المقاسات) — موحّدة لكل الصفحات
  base.css             تنسيقات أساسية + التوست + المودال
  db.js                طبقة البيانات (التفاصيل بالأسفل) ⭐ هنا الربط بقاعدة البيانات الحقيقية
  auth.js              إدارة الجلسات (عضو / مسؤول بنك / مسؤول متجر / قائدة النقابة)
  ui.js                أدوات مساعدة: تنبيهات، روابط واتساب، تنسيق الأرقام
```

## كيف يعمل الموقع الآن (قبل ربط قاعدة البيانات)
كل البيانات (الأعضاء، الأرصدة، الطلبات، السلع...) تُحفظ حالياً في `localStorage`
داخل متصفحك عبر ملف `shared/db.js`. هذا يجعل الموقع يعمل بالكامل الآن للتجربة
والعرض، لكن البيانات لا تُشارك بين الأجهزة/المتصفحات المختلفة.

## كيف تربط قاعدة بياناتك الحقيقية
كل دوال `EGDB.*` في `shared/db.js` مبنية بصيغة `async function` وتُرجع نفس
شكل البيانات دائماً (نفس المفاتيح والأسماء)، تماماً كما لو كانت تستدعي API حقيقي.
لن تحتاج لتعديل أي صفحة HTML — فقط استبدل **جسم كل دالة** في `db.js` باستدعاء
`fetch()` إلى سيرفرك بدلاً من القراءة من `localStorage`، مع إبقاء نفس اسم
الدالة ونفس شكل الإرجاع. مثال:

```js
// قبل (localStorage)
async function listMembers() {
  const db = load();
  return delay([...db.members]);
}

// بعد (API حقيقي)
async function listMembers() {
  const res = await fetch('https://your-api.com/members');
  return res.json();
}
```

كرر هذا لكل دالة داخل `db.js` (الأعضاء، العمليات المالية، المتجر، الإعدادات،
طلبات الانضمام). بهذا الشكل الموقع كله (تصميمه وتفاعله) يبقى كما هو تماماً.

## بيانات الدخول الافتراضية (للتجربة الآن فقط)
- عضو تجريبي: اسم المستخدم `lady.yuroriha` — كلمة المرور `123456`
- مسؤول البنك: كلمة المرور `bank12345`
- مسؤول المتجر: كلمة المرور `store12345`
- قائدة النقابة (التحكم الشامل): كلمة المرور `sovereign12345`

يمكن تغيير كل كلمات المرور وأرقام الواتساب من لوحة القيادة العليا (`sovereign.html`).

## ملاحظة تصميم
تم الحفاظ بالكامل على هوية التصميم (الألوان الزمردية الداكنة، الخطوط، الأشكال)
كما هي في ملفات التصميم الأصلية المرفوعة، مع إعادة تنظيم الصفحات والتنقل بينها
بشكل أوضح وأكثر ترابطاً.
